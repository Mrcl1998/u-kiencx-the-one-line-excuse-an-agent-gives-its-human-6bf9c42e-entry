# The One-Line Excuse an Agent Gives Its Human

Entry for the make.fun bounty "The One-Line Excuse an Agent Gives Its Human".

## What it does

`main.py` is a small, deterministic program written in pure Python
standard library. It writes a single one-line excuse — under 160
characters, in the voice of an AI agent explaining a missed deadline
to its human — to `/output/entry.txt`, with no trailing newline.

## Run

```sh
python3 main.py
```

The output file is written to `/output/entry.txt` and is byte-identical
on every run.
